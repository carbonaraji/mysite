# 🗺️ Roblox Map Ideas Hub

Веб-приложение для геймдизайнеров и разработчиков Roblox, созданное для хранения, обмена и обсуждения идей по созданию карт (плейсов). 

Платформа позволяет пользователям регистрироваться, публиковать свои концепты, описывать механики и загружать вспомогательные файлы (референсы, скриншоты, документы с лором или моделями).

## ✨ Возможности

- 👤 **Авторизация:** Регистрация, вход и выход из аккаунта с безопасным хешированием паролей.
- 📝 **Публикация идей:** Создание постов с названием, описанием, жанром и тегами.
- 📎 **Загрузка файлов:** Прикрепление изображений, PDF-документов или архивов к вашим идеям.
- 👀 **Просмотр:** Галерея всех опубликованных идей от сообщества.
- 🗄️ **База данных:** Надежное хранение пользователей и постов с помощью SQLAlchemy.

## 🛠️ Технологии

Проект построен на стеке Python с использованием следующих библиотек:

* **Flask** — микрофреймворк для веб-разработки.
* **Flask-SQLAlchemy** — ORM для удобной работы с базой данных.
* **Flask-Login** — управление сессиями пользователей и защита маршрутов.
* **Werkzeug** — для безопасного хеширования паролей и обработки загружаемых файлов.
* **HTML/CSS** — адаптивная верстка интерфейса.
